# Ball Popper

A small game built with plain HTML, CSS and JavaScript.  

## How to play

1. Download or clone this folder.
2. Open `index.html` in your browser.
3. Use the slider to pick how many balls sit at the top, then press **Start**.
4. Move the paddle with your mouse or the left and right arrow keys.
5. Every ball you hit disappears and adds 10 points. Clear them all to win. You have 3 lives.

## What you'll learn

All the code is in `script.js`, split into 10 numbered parts. Each part explains:

- **What this is**: the JavaScript idea it uses (variables, objects, arrays, loops, functions, events)
- **Skip this**: what breaks if that part is missing

## Try this

Comment out one part of `script.js`, refresh the page, and see what breaks.
Check your guess against the "Skip this" note.
